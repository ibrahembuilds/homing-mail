How this works

The finder checks that the company's domain receives email, then lists the address patterns companies use most, putting first any pattern already used by your other leads at that company.

{% if has_hunter %}Your Hunter.io key adds a verified result with a confidence score.{% else %}Guesses are not verified: sending to wrong addresses causes bounces, which hurt your sending reputation. A Hunter.io key (free plan available) adds verified results.{% endif %}

This tool never tests addresses by connecting to other mail servers. Providers treat that as address harvesting and block the server that does it.
